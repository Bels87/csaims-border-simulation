# Community Security Alert & Incident Management System (CSAIMS)
### Nigeria Border Communities Surveillance & Incident Tracking Simulation

This web application simulates an incident response system using short code **20200** to monitor border threats across Nigeria's frontiers (Niger, Benin, Cameroon, and Chad).

## Key Features
- **Simulated 20200 SMS Gateway:** Ingests alerts directly with village, ward, LGA, nearest landmark, and visual observation time.
- **Embedded SQLite Virtual Database:** Zero cloud dependencies; runs entirely in-memory with SQL query and dump capabilities.
- **Frontier GIS Location Map:** Tracks cross-border arms trafficking, irregular migration, and contraband corridors.
- **Inter-Agency Hub:** Coordinates response referrals across NIS, NCS, Joint Border Patrol Teams (JBPT), and Police Border Patrol.
